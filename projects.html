Machine Learning Implementations

Algorithms built from the definition rather than called from a library, mostly written during my M.S. in Computer Science at Wright State University. In each one the interesting part is the method itself: the training loop, the update rule, the selection criterion.

Source for all of these is in the code-vault repository, one directory per project, each with its own write-up.

Neural Networks

Backpropagation Regressor

A two-hidden-layer network with momentum, trained to fit f(x) = 1/x and then deliberately tested outside its training range. Inside the range it fits closely; past it the prediction degrades, because the network has no mechanism for extrapolation and its behaviour out there is set by the shape of the saturated hidden units rather than by anything about the target function. The forward and backward passes are written out, and evaluation is k-fold with MSE, RMSE and R-squared.

Associative Memory

A linear associative memory storing 38 letter images as bipolar vectors, with the memory matrix built in one shot from the pseudo-inverse rather than trained iteratively. Recall is a matrix product and a sign activation. Three conditions: clean recall, recall from corrupted input, and the harder case of building the memory from corrupted images in the first place, where the stored attractors themselves degrade.

Radial Basis Function Network

Both stages implemented: a k-means pass places the basis centres and derives each width from the spread of its assigned points, then the output layer is a linear fit over the resulting activations. Because that second stage is linear once the centres are fixed, there is no backpropagation in it at all, which is the appeal of the architecture.

Convolutional Network on Fashion-MNIST

Convolution into pooling into dense classification, with dropout, evaluated by 5-fold cross-validation. Reported with per-class precision, recall and F1 rather than accuracy alone, because Fashion-MNIST has classes that are genuinely hard to separate and an aggregate accuracy figure hides exactly that.

Classification

Naive Bayes with Sequential Forward Selection

The largest implementation here. A categorical Naive Bayes classifier that builds its likelihood tables from the training split, wrapped in a greedy forward selection that re-trains the full classifier for every candidate feature. Because it scores features against the model that will actually use them rather than against a proxy statistic, the trace of what it selected and in what order is the useful output.

Logistic Regression

Gradient descent and L2 regularisation written out, with metrics derived from a hand-counted confusion matrix, and its own forward selection scored on F1. The F1 choice is the point: the outcome is imbalanced at roughly 20% positive, so accuracy would reward a model that predicts the majority class and never fires. Runs against ten fresh random splits so the selected feature set can be compared across runs.

Gaussian Classifier

Two Gaussian classes separated by a single sigmoid unit trained on cross-entropy loss, with both derivatives derived by hand. The weight update chains them together, which is the same computation backpropagation performs at one node. The panels below track training across 25 epochs, with the error falling from 0.054 to effectively zero as the decision boundary settles between the two classes.

Perceptron

Single-layer perceptrons for AND, OR and complement, with weights derived by hand rather than learned. No training loop. The point is that these are derivable and XOR is not, which is the motivation for the multi-layer work above.

Clustering and Other Algorithms

k-means and Fuzzy c-means

Hard and soft clustering, both from scratch. Fuzzy c-means replaces hard assignment with a membership weight per point per cluster, so a point between two clusters pulls on both. Both sweep k from 2 to 10 and score each result with a Dunn index written from the definition, which is also the slowest part of the run.

Fuzzy Inference System

The textbook worked example for fuzzy inference has two inputs. This extends it to five, mapping four restaurant rating dimensions and a price tier onto a single personalised review score through triangular membership functions, a rule base and defuzzification. Combining five inputs is what makes the rule base the real work. Weighting the dimensions differently gives a different score for the same restaurant, which is the reason to use fuzzy logic instead of a weighted average.

Gale-Shapley Stable Matching

Proposal and deferred acceptance for the stable marriage problem, with an independent verifier that searches for any pair who would both rather have each other than their assigned partner. The algorithm is proven to produce stable matchings, so that check tests the implementation rather than the theory. Includes a scaling study out to n = 1000, consistent with the O(n²) bound.

Notes

Two of these projects started from a published tutorial and were extended rather than written from scratch. Both say so at the top of their write-up, and the repository records the origin of every file.

Some of the original inputs were coursework data that is not mine to redistribute, most clearly a survey of individual human respondents. Those are not published. The repository generates schema-compatible synthetic substitutes instead, so the code still runs, with the caveat that figures reproduced from it will not match my original results.
